# Jose Ramos

Proyectos de finanzas y economía aplicada: valuación de empresas, análisis de inversiones y estudios con datos de Perú y Estados Unidos.

## Portafolio

- **[Finanzas](https://github.com/joseramos709/finance-projects):** valuación de empresas, análisis de crédito, planeamiento financiero, renta fija y riesgo.
- **[Economía aplicada](https://github.com/joseramos709/economic-projects):** compras públicas, clima y agricultura, mercado laboral y política monetaria.

Los repositorios de trabajo son privados por ahora.

## Herramientas

Python, Stata, SQL y Excel para preparar datos, construir modelos y revisar resultados. Los proyectos incluyen informes, fuentes y documentación de los supuestos utilizados.
